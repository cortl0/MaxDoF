# MaxDoF
Maximum Degrees of Freedom. The Game with Six Degrees of Freedom and First-Person Perspective, featuring Realistic Physics.
## Build
[./Scripts/prepare_dependencies__build__run.sh](https://github.com/cortl0/MaxDoF/blob/main/Scripts/prepare_dependencies__build__run.sh)
## Dependencies
[Jolt Physics](https://github.com/jrouwe/JoltPhysics) (A multi core friendly rigid body physics and collision detection library)  
[OGRE-Next 3D](https://github.com/OGRECave/ogre-next) (Object-Oriented Graphics Rendering Engine Next Generation)
